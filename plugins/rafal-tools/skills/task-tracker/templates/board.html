How to resume work on To do / In progress tasks
1Open the project

Start Claude Code in the project folder (or any subfolder). The tracker prints the open tasks automatically at session start, so nothing needs to be pasted.

2Pick what to continue

continue resumes the first In progress task. resume T-003 resumes a specific one; for a To do task say start T-005. Tasks marked Waits for can start only after their dependencies are done; pick a Ready one instead.

3Claude loads only that task

It reads that single task file (goal, notes, next steps, log), tells you the next step and carries on. Done tasks and the rest of the plan are not reloaded.

4Blocked tasks

Tell Claude what changed, e.g. T-004 is unblocked: API key is in .env. It moves the task back to In progress and continues.

5One-click command

Click any open card and copy its Resume command: it opens Claude Code in the right folder with the resume prompt.
